# heart-disease-prediction-system
Machine Learning based Heart Disease Prediction System using Python, KNN, Streamlit, Pandas, NumPy, and Scikit-learn for early heart disease risk prediction and visualization.
❤️ Heart Disease Prediction System

A Machine Learning-based web application that predicts the risk of heart disease using medical parameters and the K-Nearest Neighbors (KNN) algorithm.

📌 Project Overview

The Heart Disease Prediction System helps users analyze medical data and predict the possibility of heart disease at an early stage. The system uses Machine Learning techniques for accurate prediction and provides graphical visualization for better understanding.

🚀 Features
User-friendly Streamlit interface
Heart disease prediction using KNN
Medical data preprocessing
Real-time prediction results
Graphs and visualizations
Health recommendation display
Fast and accurate analysis

⚙️ Installation Steps

Clone the repository
git clone https://github.com/your-username/heart-disease-prediction-system.git

Open project folder
cd heart-disease-prediction-system

Install required libraries
pip install -r requirements.txt

Run the Streamlit application
streamlit run app.py
